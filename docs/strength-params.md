# Параметры силы команд

Страница «Сила команд» (`/:competitionId/strength`) для футбольных турниров теперь даёт
настраивать часть параметров модели силы — с живым пересчётом таблицы (мгновенно) и вероятностей
на странице турнира (с задержкой: 1k прогонов сразу, 10k — после того как вы отпустили
ползунок/убрали фокус с поля). Для Dota 2 (The International) блок параметров по-прежнему
заглушка — формат симуляции для неё не реализован (см. TODO в `engine/formats/swiss.ts`).

## Как это работает

- `src/engine/strength.ts` — `resolveTeamStrengths(teams, params)`: та же формула Эло→атака/оборона,
  что раньше была захардкожена в `scripts/generate-seed-data.ts` при генерации `ratings.json`,
  но теперь параметризована (`ratingInfluence`) и принимает поправки по каждой команде вместо
  того, чтобы быть разовым расчётом в статике. Якорь — среднее Эло по самому турниру; после
  применения поправок атака/оборона нормализуются обратно к среднему 1.0 по полю, чтобы
  «средняя результативность» сохраняла буквальный смысл независимо от того, что накручено в
  поправках.
- `homeAdv` разложен симметрично через `√`: `λ_дома ×= √homeAdv`, `λ_гостей ÷= √homeAdv` — так
  домашнее преимущество двигает баланс дома/выезд, не утягивая за собой суммарную
  результативность матча.
- Состояние параметров живёт в Pinia-сторе (`src/stores/simulation.ts`, `strengthFor()`) и
  персистится в `localStorage` (`tournament-sim:strength:<competitionId>`) — раздельно по
  каждому турниру. При запуске полного прогона (`runSimulation`) стор передаёт параметры в Web
  Worker вместе с `config`/`teams`; воркер сам вызывает `resolveTeamStrengths` и подмешивает
  переопределения в `modelDefaults` перед вызовом `simulate()` — движок (`simulate.ts`,
  `formats/leaguePhase.ts`) при этом не меняется, параметры — это слой поверх него.

## Глобальные параметры (футбол)

| Параметр | Диапазон/тип | Смысл | Статус |
|---|---|---|---|
| Влияние рейтинга (`ratingInfluence`) | 0–2 | Насколько разница в Эло переходит в разброс атаки/обороны; 0 = все команды равны. | ✅ реализовано |
| Домашнее преимущество | множитель λ, 1.00–1.30 | Симметричный `√`-множитель на `lambdaHome`/`lambdaAway`. | ✅ реализовано |
| Средняя результативность | голов/матч, обычно 1.0–2.5 | `avgGoals` в `ModelDefaults`. | ✅ реализовано |
| Шум рейтинга σ | 0–0.3 (доля) | `modelDefaults.sigma`. | ✅ реализовано |
| Поправка на ничьи (ρ Диксона–Коулза) | вкл/выкл, −0.2…0.2 | `dixonColesTau` в движке уже был; теперь доступен переключатель. | ✅ реализовано |
| Источник рейтинга / веса смешивания | `clubElo` \| `odds` \| `mixed` \| `manual` | Сейчас источник всего один (заглушка), смешивать нечего. | ⏳ не реализовано — нет второго источника |
| Затухание формы | вес последних N матчей, 0–1 | Нужна история результатов по турам, которой сейчас нет. | ⏳ не реализовано |

## Параметры отдельной команды

| Параметр | Тип | Смысл | Статус |
|---|---|---|---|
| Переопределение Эло | число | Заменяет базовый Эло команды для расчёта силы. | ✅ реализовано |
| Ручная корректировка | ±% (−30…30) | Точечная поправка на травмы/усиления: `attack ×= 1+adj`, `defense ×= 1-adj`. | ✅ реализовано |
| Флаг «ротация в последнем туре» | булево | Снижает эффективную силу команды в конкретных турах, где место уже решено. | ⏳ не реализовано — нужен per-match хук в движке |

## Киберспорт (Dota 2)

| Параметр | Тип | Смысл | Статус |
|---|---|---|---|
| Вес LAN vs. онлайн | 0–1 | Результаты на LAN обычно показательнее — выше вес в перерасчёте рейтинга. | ⏳ не реализовано |
| Сброс рейтинга при смене ростера | вкл/выкл + доля сброса | Частичный откат рейтинга к среднему по региону при значимой замене состава. | ⏳ не реализовано |
| Увеличенный σ после патча | вкл/выкл + множитель | Временное расширение неопределённости после крупного геймплейного патча. | ⏳ не реализовано |

Блок Dota 2 не реализован не только по объёму работы: формат The International (Swiss +
плей-офф на выбывание) сам по себе ещё заглушка (`engine/formats/swiss.ts`,
`engine/formats/doubleElim.ts`), так что даже готовые параметры силы там не к чему было бы
подключать.

## Источники данных (для README и `scripts/update-data.ts`)

Перед реальным подключением любого источника — проверить актуальные условия использования,
лимиты запросов и (для платных/ограниченных API) наличие ключа. Ничего из списка ниже пока не
подключено — `ratings.json` для всех турниров, кроме состава/1-го тура ЛЧ, заполнен вручную
подобранными числами (см. README «Ограничения»).

### Футбол — сила команд

- **ClubElo** (`http://api.clubelo.com/YYYY-MM-DD`) — основной источник, бесплатный CSV с
  рейтингами европейских клубов.
- **Коэффициенты букмекеров** через The Odds API (бесплатный тариф с лимитом запросов).
  Коэффициенты переводятся в вероятности с удалением маржи (overround) — лучшая краткосрочная
  оценка, так как в них уже учтены травмы/состав на конкретный матч.
- **Opta Power Rankings** (theanalyst.com) — ориентир для ручной сверки; публичного API нет.
- **Коэффициенты УЕФА** — грубый запасной вариант при недоступности остальных источников.

### Футбол — календарь и результаты

- **football-data.org** — нужно проверить, какие именно еврокубки входят в бесплатный тариф.
- **API-Football**.
- **openfootball** на GitHub (открытые данные, без ключа).

### Dota 2

- **OpenDota API** — `/teams` отдаёт рейтинг команд, `/proMatches` — результаты матчей.
- **STRATZ API** (GraphQL, нужен токен).
- **Liquipedia** — сетка турнира и результаты; обязательно соблюдать их условия использования
  API и лимиты запросов.
- Букмекерские коэффициенты — как и для футбола, ориентир на краткосрочную силу.
